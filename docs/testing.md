# Тестирование

## Как запустить

```
source .venv/bin/activate
python manage.py test
```

Должно получиться `Ran 286 tests` и `OK`. Прогон занимает около 40 секунд. Тестам не нужна демо-база: каждый тест создаёт свою базу и данные сам.

Покрытие кода измеряется инструментом coverage из `requirements-dev.txt`:

```
pip install -r requirements-dev.txt
coverage run manage.py test
coverage report
coverage html          # подробный отчёт в htmlcov/index.html
```

Под coverage прогон идёт примерно вдвое дольше. Что входит в замер, задано в `.coveragerc`: код приложений и настроек без миграций и самих тестов.

Матрица доступа сама собирает все именованные адреса проекта. Если появится адрес без строки в матрице, тест упадёт, и права на новый адрес придётся описать явно.

Сквозной сценарий:
1. Оператор входит через форму входа и заносит 12 одинаковых жалоб.
2. Каждая жалоба получает категорию по словарю.
3. Поток по причине резко вырос, поэтому сразу появляются два уведомления, а аналитикам уходит письмо.
4. Оператор берёт одно обращение в работу и решает его.
5. Аналитик видит счётчик уведомлений, статистику, вывод о росте в отчёте, замаскированный email в выгрузке и те же числа через API.
6. После отметки «прочитано» счётчик пропадает.

## Ручная проверка

Это то, что тесты Django не видят: работа JavaScript в браузере, печать, открытие файлов в Excel. Проверка проводится на демо-базе (`python manage.py setup_demo`) в Chrome или Safari.

| Что проверить | Как | Ожидаемый результат |
|---|---|---|
| Фильтр причин по категории | «Обращения», выбрать категорию «Оплата» | в списке причин остались только причины оплаты |
| Сортировка и пагинация | «Сначала старые», затем «Дальше» | порядок сохраняется на всех страницах |
| Создание обращения | под operator «Новое обращение», текст «Курьер не приехал» | карточка с категорией «Доставка» и подсвеченными словами |
| Всплеск при создании | под operator 10-15 обращений «Не приходит код подтверждения по смс» | сообщение «Резкий рост», письмо в консоли `runserver`, счётчик у analyst |
| Графики | под analyst «Дашборд» | шесть графиков, подсказки на русском, легенда скрывает линии |
| Клик по графику | клик по столбцу «Задержка доставки» | список с этой причиной и тем же периодом |
| Без интернета | отключить сеть, обновить дашборд | графики рисуются |
| Печать отчёта | «Отчёты», «Печать» | нет меню, фильтров и кнопок, графики по ширине листа |
| Выгрузка | «Скачать XLSX», ссылка CSV «категории» | XLSX открывается с пятью листами, CSV раскладывается по колонкам, проценты с запятой |
| Права | войти как operator | нет пунктов аналитики, прямой адрес `/stats/` даёт «Нет доступа» |

Последняя проверка 10.10.2026:
- в Chromium через Playwright проверены графики, клик по графику, печать (эмуляция печати и PDF) и скачивание обеих выгрузок;
- работа без сети: браузеру запрещены все запросы, кроме адреса сервиса. Все графики дашборда, статистики, рейтинга, сравнения и отчёта нарисовались, внешних запросов страницы не делали;
- выгрузки открыты в LibreOffice Calc: XLSX читается со всеми листами и форматами процентов, CSV раскладывается по колонкам, кириллица на месте;
- остальные пункты закрыты автотестами.

В самом Microsoft Excel файлы не открывались, его в среде проверки нет. CSV рассчитан на Excel с русскими региональными настройками (разделитель «;»), при английских настройках его нужно открывать через «Данные → Из текста/CSV» или брать XLSX.

Отсутствие внешних адресов на странице проверяет и автотест `test_analyst_sees_charts_offline`.
