# Анализ обращений пользователей

Веб-приложение для хранения обращений пользователей, их категоризации и анализа: статистика, частые причины, графики, отчёты, уведомления о всплесках, REST API.

Проект в разработке. Сейчас готовы схема данных, роли, справочник категорий с автоопределением по ключевым словам и генератор демо-данных. Разделы интерфейса пока стоят заглушками. Анализ требований лежит в [docs/requirements.md](docs/requirements.md), схема базы в [docs/database.md](docs/database.md), устройство демо-данных в [docs/demo-data.md](docs/demo-data.md).

## Стек

Python 3.10 или новее (проверено на 3.13), Django 5.2, SQLite. Для аналитики pandas и numpy, для графиков Plotly, для выгрузки openpyxl, для поиска по словоформам snowballstemmer. Полный список зависимостей в `requirements.txt`.

## Запуск

Создать и активировать виртуальное окружение:

```
python -m venv .venv
source .venv/bin/activate        # macOS и Linux
.venv\Scripts\activate           # Windows
```

Установить зависимости, подготовить демо-базу и запустить сервер:

```
pip install -r requirements.txt
python manage.py setup_demo
python manage.py runserver
```

`setup_demo` применяет миграции, загружает справочник категорий, создаёт роли и демо-учётки и генерирует 6000 обращений за полгода. На чистой базе это занимает около 5 секунд. Если обращения уже есть, повторный запуск их не трогает. Пересоздать данные можно командой `python manage.py setup_demo --reset`.

Приложение откроется на http://127.0.0.1:8000/. Пароль у всех демо-учёток `demo12345`:

| Учётка | Роль | Что видит |
|---|---|---|
| operator, operator2, operator3 | Оператор | обращения, имена и email авторов |
| analyst | Аналитик | обращения без персональных данных, статистика, отчёты, уведомления |
| admin | Администратор | всё, плюс справочники и пользователи в /admin/ |

## Команды

| Команда | Что делает |
|---|---|
| `setup_demo [--reset] [--count N] [--months M] [--seed S]` | демо-база одной командой |
| `load_dictionary [--prune]` | загружает категории, причины, ключевые фразы и теги из `appeals/data/dictionary.json` |
| `setup_roles [--demo-users]` | создаёт группы ролей с правами и демо-учётки |
| `generate_appeals [--count N] [--months M] [--seed S] [--clear]` | генерирует обращения и печатает сводку |
| `recategorize` | пересчитывает автокатегории по текущему словарю, ручные не трогает |

Тесты запускаются командой `python manage.py test`.

## PostgreSQL

По умолчанию используется файл `db.sqlite3` в корне проекта. Для PostgreSQL нужно поставить драйвер (`pip install "psycopg[binary]"`) и задать переменные окружения `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_HOST`, `POSTGRES_PORT`.
